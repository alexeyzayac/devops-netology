Vector
======

Устанавливает и настраивает **Vector**

Переменные
--------------

| vars | Описание |
|--------|--------|
| vector_version | Версия Vector для установки |

Тэги
----

- vector – все задачи роли
- system – обновление кэша пакетов
- vector_config – настройка конфигурации vector

План действий
-------------

    - hosts: servers
      roles:
         - { role: vector }
